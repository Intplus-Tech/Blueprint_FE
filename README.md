# Blueprint Doc — Web Application

**Blueprint Doc** is an AI-powered e-signature landing page and web application. It combines document workflow management with forensic AI verification to enable secure document upload, review, and signing.

---

## 🚀 Features

* **Forensic AI Verification:** Built-in forensic analysis for electronic document verification and sign-off.
* **Document Upload & Handling:** Supports direct PDF uploading via standard file input and interactive drag-and-drop zones.
* **Authentication Options:** 
  * Standard Sign Up / Sign In workflow.
  * Google One Tap (SSO) integration.
* **Privacy & Governance:** Built-in cookie consent banner with granular options (Essentials, Marketing, External Media).
